# Hardware

This section of the repository contains information relating to component-level electrical hardware. 

In-progress work can be found in the EasyEDA Pro .eprj2 files, with outjob files (PDF schematic, Gerber, BOM, etc.) being generated for the most recent version.

## Main Board

The Main Board is where most of the logic and circuitry for the device lives.

## Top Board

The Top Board is an LED display to show power rail and system state.
