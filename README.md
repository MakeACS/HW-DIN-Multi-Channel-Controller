# DIN Multi-Channel Controller

The DIN Multi-Channel Controller Switch allows for MakeACS integration into much larger, more complex systems. This switch provides 4 high-voltage independently-controlled outputs, as well as a ganged status output (on if any channel is on). 

This is ideal for integration into systems with tiered permission levels or operating modes. Examples include;
* Restricting CNC machine's setup override switches to only trained staff, but otherwise allow access to the machine.
* Lock a paint booth's heating systems behind a stricter training than the ventilation systems.
* Control 4 different pieces of equipment at a workstation based on 4 independent trainings.
